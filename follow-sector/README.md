# Follow-sector darts — how to play

This is a scorekeeper for a **501-style mental game**: you track what would have happened on a real dartboard. Each **round** everyone aims at the **same target** — either one **numbered wedge (1–20)** or the **bull** — but you only learn what that target is **during** the round.

---

## Before you start

1. Enter each player’s name (you need at least one player).
2. Tap **Start game**. Turn order for **round 1** is **random**.
3. After each round, **who goes first next round** changes: players are ordered by **lowest total score first**. If two players are tied, order among them is **random**.
4. Use **Home** to return to the game picker, or **Abandon game** to end the session and go back to setup.

---

## The seven rounds

There are **seven rounds**. Each round has two phases:

### 1. Establishing the round target

Nobody knows the target yet. Players take turns trying to **be the first to register a scoring hit** that sets the target:

| What you hit | What it means |
|--------------|----------------|
| A **single, double, or triple** on wedge **1–20** | That **number** becomes the round target for everyone. |
| **Outer bull (25)** or **inner bull (50)** | The target is **bull** for everyone (both rings score later). |
| **Miss** | No target from that dart — keep going until you use all three darts or qualify. |

- Each player gets **one visit** of **up to three darts** to try to qualify (same order as the round).
- The **first dart that qualifies** fixes the target **and scores** according to that target (see below).
- Any **extra darts in that same visit** are scored **only on the target that was just set** (everything else is **0**).
- If you **never qualify** in your three darts, the next player tries.
- If **no one** qualifies after **everyone** has had their turn, the round scores **0 for all**.

**In the app:** use the strip (**Miss**, **1–20**, **Bull**), then tap **Set target** after each dart. Once someone has qualified, the round target appears next to the board.

### 2. Scoring on the fixed target

Once the target is known **for that round**:

- **Target is wedge *N*:** only hits on **wedge *N*** score — **N × (1, 2, or 3)**. **Bull and every other wedge are 0.**
- **Target is bull:** only **25** (outer) and **50** (inner) score. **All numbered wedges are 0.**

Everyone who still needs to throw gets **three darts per turn**, same as usual: pick **Miss**, **Single**, **Double**, **Triple** for each dart (or **Miss / 25 / 50** when the target is bull), then **Confirm turn**.

**Important:** The player who **set** the target does **not** get a second visit that round. Their qualifying visit **is** their only scoring visit for that round.

---

## Tie-break

If **two or more players are tied for first place** after round 7:

- Only those **tied leaders** play.
- Each **wave** picks a **new random target** (a wedge **1–20** **or** bull).
- Same scoring rules as above — three darts per turn, then confirm.
- Repeat until **one** leader is ahead.

---

## Tips for using the screen

- **Progress bar** — shows how far you are through the **seven rounds** (ticks **1–7**); in tie-break it shows the bar at full width with a warning style.
- **Dartboard** — highlights the current wedge target or emphasizes bull when the target is bull.
- **Confirm turn** — stays disabled until all three darts for that turn are chosen; the button shows a **running total** where it applies.
- **Refresh** — your game is kept for this browser tab (**session**); closing the tab usually clears it.
- **Home** — opens the main menu (`index.html`) that lists both games.
- **Abandon game** — ends the session and returns to setup.

Have fun — and keep the maths honest.
