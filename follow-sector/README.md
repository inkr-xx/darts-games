# Follow-sector — how to play

This is a scorekeeper for a “follow the wedge” style game: each round has a **randomly-established target** (a **wedge 1–20** or **bull**) and **only hits on that target score**.

---

## Setup

1. Add at least one player.
2. Tap **Start game**.
3. **Round 1 order** is randomized at game start.
4. For rounds **2–7**, the next round order is **lowest total score first** (ties are shuffled randomly).

---

## Rounds 1–7

Each round starts with **establishing the target**, then switches to **scoring on that target**.

### 1) Establish the round target

Players go in the current round order. Each player gets **up to 3 darts** to try to be the first to qualify:

- **Pick a number (1–20)** → counts as a **single wedge hit** and **qualifies immediately** (target becomes that wedge).
- **Pick Bull** → counts as **inner bull (50)** and **qualifies immediately** (target becomes bull).
- **Pick Miss** → does not qualify; you can try again until you’ve used 3 darts.

**Scoring during establishment:** the **qualifying dart scores immediately**, and any later darts you record in that same establishing sequence score **only** on the now-fixed target (everything else is 0).

If nobody qualifies after everyone has used their establishing turn, the round scores **0 for all** and the game moves to the next round.

### 2) Score on the fixed target

Once the target exists, turns are standard **3-dart scoring turns**:

- **Target wedge N:** choose **Miss / Single / Double / Triple** for each dart, scoring \(N \times 0/1/2/3\).
- **Target bull:** choose **Miss / 25 / 50** for each dart.

Then tap **Confirm turn**.

---

## Tie-break (first place only)

If two or more players are still tied for **first** after round 7:

- Only the **tied leaders** play extra waves.
- Each wave picks a **new random target** (wedge 1–20 or bull).
- Each tied leader takes **one 3-dart scoring turn** on that target (no establishment phase).
- If first is still tied, another wave starts with a new random target.

---

## Screen tips

- **Progress bar**: rounds 1–7; in tie-break it shows a full-width warning style.
- **Home** (`bi-house`): returns to the game picker.
- **Instructions** (`bi-info-circle`): opens these instructions.
- **Exit** (`bi-box-arrow-right`): abandons the current game and returns to setup.
