# Max — how to play

This is a simple 7-round scorekeeper where **highest total wins**.

## Setup

1. Add players **in throwing order** (this order stays the same for every round).
2. Press **Start game**.

## Gameplay

- The game is **7 rounds**.
- Each round, each player enters a **three-dart visit total** (0–180).
- Press **Confirm turn** to add that visit total to the player’s running total.

## End of game

- After round 7, the game ends.
- Standings are sorted by **total score (descending)**; equal totals share rank.
