# random-sector — how to play

A seven-round scorekeeper: each round everyone throws at the **same** random target — either a **numbered wedge (1–20)** or the **bull**. Throwing order stays the same all game (the order you entered at setup).

---

## Before you start

1. Enter each player’s name (at least one).
2. Tap **Start game**.
3. Use **Home** anytime to go back to the game picker; **Abandon game** clears this session and returns to setup.

---

## The seven rounds

Each round:

1. The app picks a **new random target**: one of the wedges **1–20**, **or** the **bull** (roughly a **1 in 21** shot at bull each round).
2. Everyone throws **three darts** in setup order, records **Miss / Single / Double / Triple** on a wedge target, or **Miss / 5 / 15** when the target is **bull**, then **Confirm turn**.
3. When the last player confirms, the **next round** starts automatically with a **new** random target.

### Scoring (game points — not full dartboard face value)

**Wedge target**

| You record | Points for that dart |
|------------|----------------------|
| Miss       | 0                    |
| Single     | 1                    |
| Double     | 2                    |
| Triple     | 3                    |

**Bull target**

| You record | Points for that dart |
|------------|----------------------|
| Miss       | 0                    |
| **5**      | 5 (outer bull)       |
| **15**     | 15 (bullseye)        |

Your **total score** is the sum of all these dart points across all rounds.

---

## Who wins if points are tied?

There is **no** extra throwing round. If two or more players are tied on **total score**, places are decided by:

1. Most **triple** hits on wedge rounds (multiplier “Triple” on the target wedge),
2. then most **double** hits,
3. then most **single** hits.

If **everything** matches, they **tie** for that place.

---

## Tips

- **Progress bar** — rounds **1–7**.
- **Big number / Bull** beside the board — the **current round target**.
- **Confirm turn** — disabled until all three darts are set; shows a **running total** for the turn.
- **Refresh** keeps the game in this browser tab (**session**).
- **Names** can be filled quickly next time with **Use last names** after you’ve played once.

Enjoy.
